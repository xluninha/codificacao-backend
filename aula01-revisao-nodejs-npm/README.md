# 🚀 Aula 01: Revisão Node.js e NPM
> **UC:** Codificação para Back-End
> **Data:**11/09/2026

Uma jornada técnica pelo coração do desenvolvimento *server-side* moderno — do motor V8 ao gerenciamento de pacotes com NPM.

---

## 📌 Sobre a Aula
Esta aula aborda os conceitos fundamentais do ecossistema Node.js, explorando a execução de código fora do navegador, a utilização de módulos nativos do sistema e o gerenciamento de dependências com o NPM.

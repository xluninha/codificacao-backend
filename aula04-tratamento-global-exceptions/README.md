# 🛡️ Aula 04: Tratamento de Exceções Global
> **UC:** Codificação para Back-End

Garantindo alta disponibilidade, estabilidade e segurança em aplicações Node.js.

---

## 📌 Sobre a Aula
Esta aula foca na criação de uma camada global de segurança para o servidor. Aprendemos a capturar falhas não tratadas, impedir que exceções inesperadas derrubem a aplicação em produção e registrar logs detalhados sem expor vulnerabilidades ou dados sensíveis ao usuário final.
